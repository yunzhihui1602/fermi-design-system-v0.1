# 费米 Design System V0.1

面向科研 Agent 与多后台产品的统一界面规范。

本仓库通过 GitHub Pages 发布，入口文件为 `index.html`。

## 开发指南

打开 [快速上手](https://yunzhihui1602.github.io/fermi-design-system-v0.1/#quick-start)，按顺序引入现有 CSS，即可使用原生 HTML 示例。开发指南包含 Button、Input、Select、Dialog、Table 的代码、属性、事件和键盘操作说明。

[新增渠道示例](https://yunzhihui1602.github.io/fermi-design-system-v0.1/#create-channel-demo) 演示动态模型项、校验、提交、失败重试与结果反馈。示例在浏览器内运行，刷新页面后清除演示记录。
